# メタデータ管理 UI の拡張

## 概要

Notion Sync Summary コンポーネントが拡張され、カスタムメタデータレコードを管理するための Salesforce 設定への直接リンクが提供されるようになりました。これにより、Apex によるプログラム的な削除に代わる手段がユーザーに提供されます。

## 新機能

### 1. 設定で管理ボタン
- 設定一覧のヘッダーにグローバルな「設定で管理」ボタンを追加
- Salesforce 設定のカスタムメタデータ型ページを開きます
- ユーザーがすべてのカスタムメタデータ型の定義を参照できます

### 2. 個別レコードの管理
- 各同期設定の「アクション」列に「管理」ボタンを追加
- 特定のカスタムメタデータレコードを設定画面で表示・編集できます
- レコード詳細ページへの直接アクセスを提供します

### 3. 拡張された削除モーダル
- 削除確認モーダルを更新し、代替手段に言及するようにしました
- ユーザーに対し、「削除」ボタンを使う代わりに設定で直接レコードを管理できることを案内します

## 実装の詳細

### コンポーネントの変更

#### notionSyncSummary.html
- ヘッダーセクションに「設定で管理」ボタンを追加
- 各設定のアクション列に「管理」ボタンを追加
- 削除確認モーダルに代替案のメッセージを追加

#### notionSyncSummary.js
- カスタムメタデータ型ページに遷移する `handleManageInSetup()` メソッドを追加
- 特定のレコードページに遷移する `handleManageRecord()` メソッドを追加
- 設定マッピングを更新し、`objectMetadataId` を含めるようにしました

### ナビゲーション URL

1. **カスタムメタデータ型ホーム**: `/lightning/setup/CustomMetadata/home`
2. **特定のレコード**: `/lightning/setup/CustomMetadataRecordDetail/page?address=%2F{recordId}`

これらの URL は Lightning Experience と Classic の両方で動作します（自動リダイレクト付き）。

## メリット

1. **直接アクセス**: メニューをたどらずに素早く設定にアクセスできます
2. **削除の代替手段**: プログラム的なソフト削除に代わる標準 UI のオプションを提供します
3. **完全なコントロール**: ユーザーは設定でカスタムメタデータレコードのあらゆる側面を管理できます
4. **透明性**: 設定データが実際にどこに保存されているかをユーザーに示します

## 使い方

1. 「設定で管理」をクリックして、すべてのカスタムメタデータ型を表示します
2. 特定の行で「管理」をクリックして、その設定レコードを表示・編集します
3. 設定画面では、ユーザーは次のことができます:
   - すべての項目の値を表示
   - レコードを直接編集
   - レコードを削除（ハード削除）
   - レコードを複製
   - 関連レコードを表示

## 注意事項

- プログラム的な削除機能（ソフト削除）は引き続き利用可能です
- 設定での管理は、UI でのソフト削除に対してハード削除の機能を提供します
- 設定で行った変更は、メタデータデプロイのタイミングにより、UI に反映されるまで少し時間がかかる場合があります
